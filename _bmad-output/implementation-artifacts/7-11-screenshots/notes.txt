Story 7.11 — Papa's first wave, captures (D13)

How: a throwaway Playwright file (deleted), Chromium, 844 × 390 CSS px, deviceScaleFactor 2, frozen with
`__PP__.freeze` and stepped with `advance`. `salon_kitchen` with `?threats=off` for the idles, the start and the
brake; `chambre_night` (loaded with `loadLevel`, seed 1) in `stealth_exit` (`StartSequence`) for the tiptoe, with
a floor tap and `HoldAnywhere` for the held breath, once more with `setPapaLook({ hasMashOnCheek: true })`.
Each `<name>.png` is the full frame; each `<name>_crop4x.png` is a 90 × 90 CSS px crop around Papa cut from a
screenshot of that same frame, ×4 nearest neighbour. « dpr » is the drawn pixel ratio (canvas.width /
clientWidth): the game stepped down to 1.5 on the longer runs (headless GPU, `adaptivePixelRatio.ts`).
